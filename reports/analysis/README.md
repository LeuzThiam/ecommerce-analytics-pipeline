# Résultats des analyses Python

Ces résultats ont été générés depuis les marts PostgreSQL par
`python -m src.analysis.report`.

## Constats principaux

- Le meilleur mois est **2014-12** avec un revenu net de
  **138,914.24 USD**.
- Les **591 acheteurs récurrents** génèrent
  en moyenne **120.08 USD** par
  client.
- Le premier canal en revenu net est **gsearch / nonbrand**, avec
  **1,074,110.39 USD**.
- Le funnel convertit **6.83%** des sessions en
  commandes.
- Le produit le plus rentable est **The Original Mr. Fuzzy**, avec un
  profit net de **677,055.37 USD**.
